# Cryptoverse - Cryptocurrency Application

Cryptoverse is a comprehensive cryptocurrency application built using React, Redux Toolkit, Ant Design, and Chart.js. It fetches real-time cryptocurrency data and global crypto news using RapidAPI.

---

## Features

- **Global Crypto Statistics**: Overview of total cryptocurrencies, market cap, 24h volume, and markets.
- **Top Cryptocurrencies**: In-depth details, price charts, and live data for top cryptocurrencies.
- **Cryptocurrency Details**: Individual currency details, market history, and links to official websites/exchanges.
- **Crypto News**: Up-to-date cryptocurrency news from Bing News Search.

---

## Tech Stack

- **Frontend**: React.js, Ant Design (antd)
- **State Management**: Redux Toolkit, RTK Query
- **Charts**: Chart.js, react-chartjs-2
- **APIs**: Coinranking API, Bing News Search API (via RapidAPI)
